# Console Page

The console page layout coordinates an app bar, persistent navigation, and a flexible workspace. Wide containers support expanded, compact, and hidden sidebar states; narrow containers replace the sidebar control with a native app-bar menu.

## Interactive Console

The sidebar button below cycles through expanded, compact, and hidden states. Resize the page to a compact width to see the app-bar menu replace the persistent sidebar.

## Sidebar states

Apply state modifiers to the `.console-page` root. The layout owns the transition and keeps the content grid synchronized with the sidebar.

| Class | Result |
|-------|--------|
| `.console-page-sidebar-compact` | Collapses the sidebar to an icon rail and hides labels |
| `.console-page-sidebar-hidden` | Removes the persistent sidebar and lets main content fill the frame |

Use `.console-page-sidebar-toggle` for the wide-container control. Update its accessible name or pressed state whenever application code changes the sidebar state.

## Anatomy

| Class | Role |
|-------|------|
| `.console-page` | Container-query root and state owner |
| `.console-page-frame` | App bar, sidebar, and content grid |
| `.console-page-appbar` | Top application bar |
| `.console-page-sidebar` | Persistent wide-container navigation |
| `.console-page-sidebar-header` | Workspace or product identity |
| `.console-page-sidebar-body` | Scrollable navigation content |
| `.console-page-sidebar-footer` | Account or secondary actions |
| `.console-page-main` | Primary workspace content |
| `.console-page-nav-label` | Sidebar section label |
| `.console-page-sidebar-toggle` | Expanded/compact/hidden state control |
| `.console-page-menu-trigger` | Compact-container menu trigger |
| `.console-page-mobile-menu` | Compact-container navigation surface |

## Compact containers

On small containers, the persistent sidebar and its toggle are removed from the layout. The `.console-page-menu-trigger` becomes available in the app bar and opens `.console-page-mobile-menu`. The example uses native `popover`, `popovertarget`, and anchor positioning for light dismissal, Escape-key support, and predictable focus behavior.

Repeat the same destinations and active state in desktop and compact navigation. Do not render two independently focusable navigation regions at the same time.

## Accessibility

- Label the persistent and compact navigation landmarks.
- Point the sidebar toggle's `aria-controls` at the sidebar and keep its name synchronized with the next action.
- Use `aria-current="page"` for the active destination.
- Keep account actions in buttons or links; the avatar alone is not an accessible name.
- Preserve logical focus when the sidebar is hidden and allow the native popover to close with Escape.
