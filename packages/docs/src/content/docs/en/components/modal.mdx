# Modal

Modal is DuskMoon's legacy CSS overlay API. It uses a regular element with `.modal`; it does **not** style or replace the native HTML dialog element. For new accessible modal interactions, use the [Dialog](/duskmoonui/docs/en/components/dialog/) component.

The legacy API remains available for existing applications that already own visibility, focus management, Escape handling, background inertness, and focus restoration.

> Adding `.modal-open`, `aria-modal="true"`, or visible CSS does not create native modal behavior. Keep existing Modal integrations working, but start new modal tasks with `<dialog class="dialog">` opened through `showModal()`.

## Basic usage

The complete structure places `.modal-box` and `.modal-backdrop` inside `.modal`. This CSS-only example uses `:target` so the preview works without documentation-side JavaScript.

## Motion and backdrop

Motion modifiers change the box transition. Backdrop modifiers belong on the `.modal-backdrop` child. Reduced-motion preferences remove the transitions.

      <a class="modal-close" href="#demo-modal-motion-trigger" aria-label="Close modal">×</a>
    </div>
    <div class="modal-body"><p>This surface uses the blurred backdrop variant.</p></div>
  </div>
  <a class="modal-backdrop modal-backdrop-blur" href="#demo-modal-motion-trigger" aria-label="Close modal"></a>

Motion classes are `.modal-slide-up`, `.modal-slide-down`, and `.modal-zoom`. Backdrop classes are `.modal-backdrop-light`, `.modal-backdrop-blur`, and `.modal-no-backdrop`.

## Responsive and scrollable content

`.modal-responsive` becomes a bottom-aligned sheet on narrow screens. `.modal-scrollable` constrains a long body. Other content modifiers are `.modal-centered` and `.modal-no-padding`.

## State APIs

Modal retains three legacy state mechanisms:

- Add `.modal-open` to `.modal` from an existing application controller.
- Navigate to a `.modal` ID to activate its `:target` state.
- Place `.modal-toggle` immediately before `.modal` and control the checkbox with associated labels.

```html
<input class="modal-toggle" id="legacy-modal-toggle" type="checkbox" />
<div class="modal" role="dialog" aria-labelledby="legacy-modal-title">
  <div class="modal-box">
    <h2 class="modal-title" id="legacy-modal-title">Legacy modal</h2>
    <label for="legacy-modal-toggle">Close</label>
  </div>
  <label class="modal-backdrop" for="legacy-modal-toggle" aria-label="Close modal"></label>
</div>
```

Use `body.modal-open` when your controller's scroll-lock policy must prevent background scrolling. Scroll locking is separate from background inertness: the body class does not make background controls inert, contain focus, or create modal semantics. The CSS class does not manage application state by itself.

## Accessibility responsibilities

Legacy Modal supplies styling, not modal behavior. Consumers must:

- Move focus into the modal when it opens and restore focus to the trigger when it closes.
- Contain keyboard focus and make background content inert while the modal is active.
- Add Escape dismissal and ensure every close control has an accessible name.
- Provide an accessible name through `aria-labelledby` or `aria-label`.
- Add `aria-modal="true"` only after the implementation actually prevents interaction with background content.

The CSS-only `:target` and checkbox examples demonstrate appearance and state changes; they are not complete accessible modal implementations. Prefer [Dialog](/duskmoonui/docs/en/components/dialog/) when native browser behavior is available to the application.

Backdrop dismissal is also an application decision. `.modal-backdrop` supplies the visual/click target used by existing markup, but the controller must decide whether backdrop activation closes a particular task. Destructive and multi-step flows may require an explicit close or cancel action.

## API reference

| Area | Classes |
| --- | --- |
| Structure | `.modal`, `.modal-box`, `.modal-header`, `.modal-title`, `.modal-body`, `.modal-footer`, `.modal-action`, `.modal-close`, `.modal-backdrop` |
| Size | `.modal-sm`, `.modal-md`, `.modal-lg`, `.modal-xl`, `.modal-full` |
| Placement | `.modal-top`, `.modal-middle`, `.modal-bottom` |
| Motion | `.modal-slide-up`, `.modal-slide-down`, `.modal-zoom` |
| Backdrop | `.modal-backdrop-light`, `.modal-backdrop-blur`, `.modal-no-backdrop` |
| Content | `.modal-responsive`, `.modal-scrollable`, `.modal-centered`, `.modal-no-padding`, `.alert-dialog` |
| State | `.modal-open`, `.modal-toggle`, `:target`, `body.modal-open` |

Modal does not define public custom properties. It consumes DuskMoon surface, content, radius, shadow, scrim, and motion tokens across themes.
