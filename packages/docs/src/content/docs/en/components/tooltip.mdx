# Tooltip

Tooltips display brief, helpful text when users show interest in an element (hover, focus, or long-press).

> **Breaking change**: Tooltips now use the native Popover API (`popover="hint"`) with Interest Invokers (`interestfor`) and CSS Anchor Positioning. The old wrapper + `.tooltip-content` markup is no longer supported.

## Basic Usage

Pair a trigger (`interestfor` + `anchor-name`) with a tooltip surface (`popover="hint"` + `position-anchor`):

<ComponentShowcase title="Basic Tooltip" code={`<button class="btn btn-primary" interestfor="demo-tip-basic" style="anchor-name: --demo-tip-basic">Hover me</button>
<div id="demo-tip-basic" popover="hint" class="tooltip" style="position-anchor: --demo-tip-basic">This is a tooltip</div>`} />

## Browser Support

| Feature | Support |
|---------|---------|
| Popover API (`popover="hint"`) | Chrome 133+, Edge 133+ |
| Interest Invokers (`interestfor`) | Chrome 135+, Edge 135+ |
| CSS Anchor + `position-area` | Chrome 125+ (HiDPI fixes in Chrome 130+) |

On unsupported browsers, keep a `title` attribute on the trigger as a progressive-enhancement fallback.

## React Example

```tsx
type TooltipProps = {
  id: string;
  content: string;
  position?: 'top' | 'bottom' | 'left' | 'right';
  children: React.ReactElement;
};

export function Tooltip({ id, content, position = 'top', children }: TooltipProps) {
  const anchor = `--${id}`;
  return (
    <>
      {React.cloneElement(children, {
        interestFor: id,
        style: { ...(children.props.style || {}), anchorName: anchor },
      })}
      <div
        id={id}
        popover="hint"
        className={`tooltip tooltip-${position}`}
        style={{ positionAnchor: anchor }}
      >
        {content}
      </div>
    </>
  );
}
```

## API Reference

### Surface classes (on the popover element)

| Class | Description |
|-------|-------------|
| `.tooltip` | Base tooltip surface (required with `[popover]`) |
| `.tooltip-top` | Preferred `position-area: top` (default) |
| `.tooltip-bottom` | Preferred `position-area: bottom` |
| `.tooltip-left` | Preferred `position-area: left` |
| `.tooltip-right` | Preferred `position-area: right` |
| `.tooltip-primary` / `.tooltip-secondary` / `.tooltip-tertiary` / `.tooltip-info` / `.tooltip-success` / `.tooltip-warning` / `.tooltip-error` / `.tooltip-light` | Color variants |
| `.tooltip-multiline` | Allow wrapping (max-width: 16rem) |
| `.tooltip-rich` | Rich content (max-width: 20rem) |
| `.tooltip-interactive` | Enable pointer events on the surface |

### Trigger utilities

| Class | Description |
|-------|-------------|
| `.tooltip-delay` | `interest-delay: 300ms` |
| `.tooltip-delay-long` | `interest-delay: 500ms` |

### Attributes & CSS

| Name | Where | Description |
|------|-------|-------------|
| `interestfor` | Trigger | Links interest to the tooltip id |
| `popover="hint"` | Surface | Hint popover (does not dismiss `auto` popovers) |
| `anchor-name` | Trigger | Explicit named anchor |
| `position-anchor` | Surface | Binds surface to the named anchor |
| `position-area` / `position-try-fallbacks` | CSS | Preferred placement + flip fallbacks |

### Rich content

| Class | Description |
|-------|-------------|
| `.tooltip-rich-title` | Title in rich tooltip |
| `.tooltip-rich-description` | Description in rich tooltip |

## Accessibility

- Prefer interactive triggers (`button`, links, form controls) so keyboard focus works with interest invokers
- Use `aria-describedby` pointing at the tooltip id when helpful
- Keep text brief; do not hide critical information only in a tooltip

```html
<button interestfor="demo-tip-a11y" aria-describedby="demo-tip-a11y" style="anchor-name: --demo-tip-a11y">Help</button>
<div id="demo-tip-a11y" popover="hint" class="tooltip" style="position-anchor: --demo-tip-a11y" role="tooltip">
  Click for assistance
</div>
```
