# Hero

Hero layers foreground content over an optional background or overlay. The primitive controls structure only; use theme utilities for height, spacing, imagery, color, and typography. Existing `.home-page-hero` layouts remain independent.

## Overlay

An overlay is decorative and should normally be hidden from assistive technology. Give meaningful background images equivalent text elsewhere when they convey content.

## API

| Class | Purpose |
|---|---|
| `.hero` | Full-width single-area grid |
| `.hero-content` | Readable foreground layer |
| `.hero-overlay` | Non-interactive, presentation-neutral covering layer |
| `.hero-center`, `.hero-start`, `.hero-end` | Logical content alignment |
