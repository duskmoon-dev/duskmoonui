# Hover 3D

Optional effect: excluded from the default core and standalone bundles.

## Import

```css
@import "tailwindcss";
@import "@duskmoon-dev/core";
@import "@duskmoon-dev/core/effects/hover-3d";
```

Individual CSS: `@duskmoon-dev/core/effects/hover-3d.css` (also available via the `style` export condition on `@duskmoon-dev/core/effects/hover-3d`).
JavaScript `import { css, styles } from "@duskmoon-dev/core/effects/hover-3d"` exposes CSS text and a nullable CSSStyleSheet (null during SSR). It is not an interaction runtime.

## API And Accessibility

Class: `hover-3d`. Set `--hover-3d-x`/`--hover-3d-y` to small angles (defaults 2deg/-2deg). No overlay intercepts links, buttons or inputs. Tilt is disabled while a nested control has focus, on coarse/no-hover input, under reduced motion and in print. Default Card remains unchanged. Without transforms the original content is usable. No pointer-tracking controller is required or installed.
