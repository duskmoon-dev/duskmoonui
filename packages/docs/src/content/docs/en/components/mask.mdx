# Mask

Mask clips images or background content into a small catalog of useful shapes. It is visual only: meaningful images still require useful alternative text. When `clip-path` is unavailable, content remains visible as a rectangular fallback.

## Image content

Set both dimensions or an aspect ratio when you need a predictable silhouette. The base class uses `object-fit: cover` for replaced elements.

## API

| Class | Purpose |
|---|---|
| `.mask` | Base clipping and replaced-element behavior |
| `.mask-circle` | Circular clip |
| `.mask-squircle` | Soft continuous-looking rounded square |
| `.mask-square` | Explicit square clip |
| `.mask-diamond` | Diamond clip |
| `.mask-hexagon` | Regular hexagonal clip |
| `.mask-triangle` | Upward triangle clip |
