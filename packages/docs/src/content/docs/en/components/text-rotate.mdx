# Text Rotate

Text Rotate cycles vertically through two to six phrases. It is a CSS-only optional effect and is excluded from the default bundles.

## Import

```css
@import "tailwindcss";
@import "@duskmoon-dev/core";
@import "@duskmoon-dev/core/effects/text-rotate";
```

Individual CSS: `@duskmoon-dev/core/effects/text-rotate.css` (also available via the `style` export condition on `@duskmoon-dev/core/effects/text-rotate`).
JavaScript `import { css, styles } from "@duskmoon-dev/core/effects/text-rotate"` exposes CSS text and a nullable CSSStyleSheet (null during SSR). It is not an interaction runtime.

## API and accessibility

The `.text-rotate` viewport contains one track, and that track contains two to six phrases. Rotation starts automatically, lasts 10 seconds by default, and pauses while hovered or while focus is inside. Set `--text-rotate-duration` to change the cycle length. Add `.text-rotate-paused` for a persistent paused state.

Give the changing visual words `aria-hidden="true"` and put stable wording in the surrounding element's accessible name. Reduced-motion mode and print show the first phrase without animation. A persistent pause button is optional; if provided, application code must toggle `.text-rotate-paused`, `aria-pressed`, and the button label. Do not put interactive controls inside the rotating phrases.

```js
const button = document.querySelector('[data-text-rotate-demo] button');
const text = document.querySelector('[data-text-rotate-demo] .text-rotate');

button.addEventListener('click', () => {
  const paused = text.classList.toggle('text-rotate-paused');
  button.setAttribute('aria-pressed', String(paused));
  button.textContent = paused ? 'Resume animation' : 'Pause animation';
});
```
