# Chat

Chat provides CSS-only primitives for conversational interfaces. It supports user and assistant rows, avatars, message bubbles, reasoning traces, tool calls, and live streaming states without requiring JavaScript.

## Basic Usage

Use `.chat` with either `.chat-start` or `.chat-end` to place a message row. Put any existing `.avatar` inside `.chat-avatar`.

Wrap a transcript in `.chat-scroll` when the conversation should scroll inside a fixed-height panel. Scroll behavior defaults to `smooth`. Pair **agent replies** with matching indicators via `data-chat-tl` so Scroll-Driven Animations can sync the rail with visible assistant rows.

## Scroll-Driven Indicators

`.chat-scroll` hoists named view timelines with `timeline-scope` (`--chat-1` … `--chat-24`). Pair **agent / assistant rows only** (`.chat-start`) with matching indicators: `.chat[data-chat-tl="N"]` declares `view-timeline-name`, and `.chat-scroll-indicator[data-chat-tl="N"]` binds `animation-timeline` + `animation-range: entry 0% exit 100%`.

User turns stay in the transcript but do not get ticks. Click an indicator to jump to that agent response **inside** `.chat-scroll` — use `button` + `data-chat-target` (not bare `href="#…"`), otherwise the document will scroll. Docs demos wire the click handler; app code should call `scroller.scrollTo(...)` the same way.

Requires a browser that supports Scroll-Driven Animations. Unsupported browsers still scroll smoothly; indicators stay in the idle style.

## API Reference

### Structure

| Class / Attribute | Description |
|---|---|
| `.chat-scroll` | Scrollable transcript (`overflow-y: auto`, `scroll-behavior: smooth`, `timeline-scope` for `--chat-1`…`--chat-24`) |
| `.chat-scroll-track` | Sticky indicator rail (use `aria-hidden="true"` when indicators are decorative/duplicative) |
| `.chat-scroll-body` | Message column that holds `.chat` rows |
| `.chat-scroll-indicator` | Dash indicator for an agent reply; bind with `data-chat-tl="N"` + `data-chat-target="message-id"` (prefer `<button>`, not hash links) |
| `[data-chat-tl="N"]` | Shared slot `1`–`24` on **agent** `.chat` rows and their indicators |
| `[data-chat-target]` | Message id to scroll to inside `.chat-scroll` (docs demo wires the click handler) |
| `.chat` | Row wrapper for avatar and message stack |
| `.chat-start` | Left-aligned row, commonly used for assistant messages |
| `.chat-end` | Right-aligned row, commonly used for user messages |
| `.chat-avatar` | Avatar slot; compose with the existing `.avatar` component |
| `.chat-header` | Small muted metadata above the message stack |
| `.chat-footer` | Small muted metadata below the message stack |
| `.chat-bubble` | Message bubble with directional tail; may contain reasoning, tools, and `.chat-bubble-content` |
| `.chat-bubble-content` | Final answer slot when the bubble also holds collapsible blocks |

### Bubble Modifiers

| Class | Description |
|---|---|
| `.chat-bubble-primary` | Primary color bubble |
| `.chat-bubble-secondary` | Secondary color bubble |
| `.chat-bubble-tertiary` | Tertiary color bubble |
| `.chat-bubble-info` | Info color bubble |
| `.chat-bubble-success` | Success color bubble |
| `.chat-bubble-warning` | Warning color bubble |
| `.chat-bubble-error` | Error color bubble |
| `.chat-bubble-filled` | Saturated filled style for color variants |
| `.chat-bubble-xs` | Extra small bubble |
| `.chat-bubble-sm` | Small bubble |
| `.chat-bubble-md` | Medium bubble, explicit alias of the base size |
| `.chat-bubble-lg` | Large bubble |
| `.chat-bubble-streaming` | Adds a streaming caret after bubble content |

### LLM Classes

| Class | Description |
|---|---|
| `.chat-reasoning` | Collapsible reasoning trace using `<details>`; place inside `.chat-bubble` |
| `.chat-reasoning-body` | Reasoning content stack; may nest streaming `.chat-tool` blocks |
| `.chat-tool` | Collapsible tool call block using `<details>`; inside the bubble, or nested in reasoning |
| `.chat-tool-header` | Summary content for tool name and status text |
| `.chat-tool-call` | Tool call payload slot |
| `.chat-tool-result` | Tool result payload slot |
| `.chat-tool-pending` | Pending tool status |
| `.chat-tool-running` | Running tool status with activity indicator |
| `.chat-tool-success` | Successful tool status |
| `.chat-tool-error` | Failed tool status |
| `.chat-typing` | Typing indicator dots |

## Accessibility

- Use visible text for tool statuses such as `Pending`, `Running...`, `Done`, and `Failed`.
- Add `aria-label="Assistant is typing"` to the bubble that contains `.chat-typing`, or place `aria-live="polite"` on the row stack.
- Prefer native `<details>` and `<summary>` for reasoning and tool blocks so keyboard interaction works without custom JavaScript.
- `.chat-scroll` respects `prefers-reduced-motion` by switching `scroll-behavior` to `auto` and disabling indicator animations. Give the scroll container a reachable height. Map ticks only to agent reply starts. Prefer `<button data-chat-target>` over hash links so navigation stays inside the panel; give each indicator an `aria-label`.
