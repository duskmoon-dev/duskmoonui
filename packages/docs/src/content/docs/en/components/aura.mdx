# Aura

Aura wraps content with a rotating border light. It is an optional effect, so it is excluded from the default core and standalone bundles.

## Import

```css
@import "tailwindcss";
@import "@duskmoon-dev/core";
@import "@duskmoon-dev/core/effects/aura";
```

Individual CSS: `@duskmoon-dev/core/effects/aura.css` (also available via the `style` export condition on `@duskmoon-dev/core/effects/aura`).
JavaScript `import { css, styles } from "@duskmoon-dev/core/effects/aura"` exposes CSS text and a nullable CSSStyleSheet (null during SSR). It is not an interaction runtime.

## Basic Aura

Wrap one component in `.aura`. The effect follows the current theme color and starts rotating automatically.

## API and accessibility

| Class | Purpose |
| --- | --- |
| `aura` | Rotating current-color border light |
| `aura-dual`, `aura-rainbow`, `aura-holo` | Multicolor styles |
| `aura-gold`, `aura-silver`, `aura-glow` | Material and soft-glow styles |
| `aura-xs` through `aura-xl` | Border and glow sizes |

Set `color` to customize the default Aura, and set `--aura-duration` to change the rotation speed. Keep space around the wrapper because an ancestor with `overflow: hidden` can crop its glow. Reduced-motion mode freezes the light, and print removes the decoration. Aura is decorative and needs no extra ARIA.
