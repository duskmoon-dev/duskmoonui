# Bottom Sheet

Bottom sheets are surfaces containing supplementary content that are anchored to the bottom of the screen. They're commonly used on mobile devices for contextual actions, settings, or additional information.

## Native non-modal bottom sheet

Use `popover="auto"` for a non-modal surface in the browser's top layer. The browser handles Escape, outside-click dismissal, and focus restoration when dismissed with Escape. It does not make the rest of the page inert or trap focus.

## Native modal bottom sheet

Use a native `dialog` with `show-modal` for modal interaction: the browser makes the background inert, keeps keyboard focus inside, and returns focus to the opener on close. `closedby="any"` enables outside-click dismissal in supporting browsers; Escape and the explicit close button remain available. Omit `closedby="any"` to require Escape or a close action. The scrim comes from `::backdrop`; no separate backdrop element is needed.

### State, positioning, and motion

Native surfaces use `:popover-open` or the dialog's `open` attribute. Do not add legacy visibility classes or toggle `open` directly for modal dialogs. Invoker commands require browser support; applications targeting older browsers can call `showPopover()` / `hidePopover()` and `showModal()` / `close()` as a compatibility fallback.

These panels attach to viewport edges rather than their trigger, so they do not need an anchor name. Opening and closing transitions preserve the top layer with discrete `display` / `overlay` transitions. Reduced-motion preferences disable these transitions.

## Variants and content

Use `bottomsheet-sm` (50vh), `bottomsheet-lg` (95vh), or `bottomsheet-full` (100vh). The default maximum height is 90vh. `bottomsheet-peek`, `bottomsheet-half`, and `bottomsheet-expanded` provide 30vh, 50vh, and 90vh maximum heights.

Add `bottomsheet-responsive` to change the bottom sheet into a right-side sheet at 768px. `bottomsheet-content` scrolls independently; `bottomsheet-header` and `bottomsheet-footer` hold the heading and actions. The sheet includes bottom safe-area padding.

`bottomsheet-handle` provides a visual drag handle only; dragging and detent selection require application behavior. Use `bottomsheet-list` / `bottomsheet-item` for action lists or `bottomsheet-grid` / `bottomsheet-grid-item` for a grid of actions.

## Legacy class-controlled API

Existing applications can continue using `.bottomsheet.show` and `.bottomsheet-backdrop.show`. This API does not provide native focus management, Escape handling, background inertness, or light dismissal. Applications must implement those behaviors themselves. `bottomsheet-persistent` uses absolute positioning for an embedded sheet.

The CSS class prefix is `bottomsheet-`, not `bottom-sheet-`. Use `bottomsheet-content` for the body. A modal sheet is a native `dialog`, rather than a `bottomsheet-modal` class.
