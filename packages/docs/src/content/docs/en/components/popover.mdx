# Popover

Popovers display rich contextual content in an overlay positioned relative to a trigger element.

> Uses the native [HTML Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) with CSS Anchor Positioning (`anchor-name`, `position-anchor`, `position-area`, `position-try-fallbacks`).

## Basic Usage

<ComponentShowcase title="Basic Popover" code={`<button class="btn btn-primary" style="anchor-name: --demo-basic-anchor" popovertarget="demo-basic-popover">Show Popover</button>
<div class="popover" id="demo-basic-popover" popover style="position-anchor: --demo-basic-anchor">
  <div class="popover-body">
    This is a basic popover with some informational content. It tracks the button on scroll!
  </div>
</div>`} />

## CSS Anchor Positioning

Link the trigger and surface with explicit named anchors, then let CSS place the surface with `position-area` and flip via `position-try-fallbacks`:

```html
<button style="anchor-name: --my-anchor" popovertarget="my-popover">Open</button>
<div class="popover popover-bottom" id="my-popover" popover style="position-anchor: --my-anchor">
  Content that tracks the button on scroll!
</div>
```

### Browser Support

- Popover API: Chrome 114+, Firefox 125+, Safari 17+
- CSS Anchor + `position-area`: Chrome 125+ (HiDPI fixes in Chrome 130+)
- Residual risk: nested scroll containers combined with ancestor `transform` / `will-change` compositing layers on older Chromium forks

## Framework Example (React)

```tsx
export function InfoPopover() {
  return (
    <>
      <button
        className="btn btn-primary"
        popoverTarget="demo-react-popover"
        style={{ anchorName: '--demo-react-popover' }}
      >
        Show Popover
      </button>
      <div
        id="demo-react-popover"
        popover=""
        className="popover popover-bottom"
        style={{ positionAnchor: '--demo-react-popover' }}
      >
        <div className="popover-body">Native Popover API — no open state required.</div>
      </div>
    </>
  );
}
```

## API Reference

### CSS Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `--popover-color-intensity` | `30%` | Theme color mix strength for color variants |

### Class Names

| Class | Description |
|-------|-------------|
| `.popover` | Base surface (required with `[popover]`) |
| `.popover-top` / `.popover-bottom` / `.popover-left` / `.popover-right` | Preferred `position-area` |
| `.popover-start` / `.popover-end` | Alignment variants |
| `.popover-sm` / `.popover-lg` / `.popover-full` | Size variants |
| `.popover-dark` / `.popover-primary` / `.popover-secondary` / `.popover-tertiary` / `.popover-surface-highest` | Color themes |
| `.popover-no-arrow` | Hide arrow |
| `.popover-modal` | Stronger backdrop |
| `.popover-menu` | Compact padding for menu lists |

### Native attributes

| Attribute | Description |
|-----------|-------------|
| `popover` | Auto light-dismiss popover |
| `popover="manual"` | No light-dismiss |
| `popovertarget` | Links trigger to popover id |
| `popovertargetaction` | `show` / `hide` / `toggle` |

### CSS Anchor Positioning

| Property | Where | Description |
|----------|-------|-------------|
| `anchor-name` | Trigger (inline) | Names the anchor |
| `position-anchor` | Surface (inline) | Binds surface to that name |
| `position-area` | CSS class | Preferred placement |
| `position-try-fallbacks` | CSS | Flip when space is tight |

### Structure

| Class | Description |
|-------|-------------|
| `.popover-arrow` | Optional arrow |
| `.popover-header` / `.popover-title` / `.popover-body` / `.popover-footer` / `.popover-close` | Layout pieces |
| `.popover-menu-item` / `.popover-menu-divider` | Menu items |
