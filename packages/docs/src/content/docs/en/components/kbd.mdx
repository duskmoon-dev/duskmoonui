# Kbd



## Import

```css
@import "tailwindcss";
@import "@duskmoon-dev/core";
```

Individual CSS: `@duskmoon-dev/core/components/kbd.css` (also available via the `style` export condition on `@duskmoon-dev/core/components/kbd`).
JavaScript `import { css, styles } from "@duskmoon-dev/core/components/kbd"` exposes CSS text and a nullable CSSStyleSheet (null during SSR). It is not an interaction runtime.

## API And Accessibility

Apply `kbd` only to styled keys. Sizes: `kbd-xs`, `kbd-sm`, default, `kbd-lg`; colors: `kbd-primary`, `kbd-secondary`, `kbd-tertiary`, `kbd-info`, `kbd-success`, `kbd-warning`, `kbd-error`; `kbd-ghost` removes the border.

Use native `kbd` for user input, with readable key names and separators for combinations. This is presentation, not shortcut registration. The application handles platform-specific names and actual key events. Existing unclassed `.markdown-body kbd` styling is preserved, and neither individual export imports the other. No global unclassed `kbd` styling is introduced.
