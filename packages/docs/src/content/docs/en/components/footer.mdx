# Footer

Footer arranges arbitrary groups in a responsive grid on a semantic DuskMoon surface. Use the native `<footer>` landmark and `<nav>` elements with accessible labels. Existing `.home-page-footer` remains supported separately.

## Explicit orientation

Use `.footer-horizontal` when the groups must remain in columns, and `.footer-vertical` when they must remain in a single column. The default auto-fit grid is responsive without relying on the viewport.

## API

| Class | Purpose |
|---|---|
| `.footer` | Responsive auto-fit grid with semantic surface colors |
| `.footer-title` | Group heading treatment |
| `.footer-center` | Centered placement and text |
| `.footer-horizontal` | Explicit column flow |
| `.footer-vertical` | Explicit single-column flow |
