# Stack

Stack places direct children in the same CSS Grid area. The first child stays in front while later children form subtle layers behind it—no consumer-authored absolute positioning is required.

## Direction

Use a directional class on the stack. Inline directions follow the document's writing direction.

<ComponentShowcase title="Directional stacks" code={`<div class="flex flex-wrap gap-10">
  <div class="stack stack-start">

    <div class="card bg-secondary-container" aria-hidden="true"></div>
  </div>
  <div class="stack stack-end">
    <div class="card card-bordered"><div class="card-body">End</div></div>
    <div class="card bg-tertiary-container" aria-hidden="true"></div>
  </div>
</div>`} />

## API

| Class | Purpose |
|---|---|
| `.stack` | Grid overlap with a subtle bottom offset |
| `.stack-top`, `.stack-bottom` | Block-axis layer direction |
| `.stack-start`, `.stack-end` | Logical inline-axis layer direction |

All children contribute to intrinsic grid sizing. If decorative duplicate layers contain no meaningful content, mark them `aria-hidden="true"`.
